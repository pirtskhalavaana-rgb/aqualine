# Aqualine • Black Friday

## გაშვება საკუთარ კომპიუტერზე

დააყენეთ Node.js 24 LTS ან თავსებადი უფრო ახალი ვერსია. გახსენით ტერმინალი პროექტის საქაღალდეში. დამატებითი npm პაკეტები და ცალკე მონაცემთა ბაზის სერვერი საჭირო არ არის.

macOS / Linux (Bash):

    read -rs -p 'Admin password: ' ADMIN_PASSWORD
    export ADMIN_PASSWORD
    npm start

Windows PowerShell 7:

    $env:ADMIN_PASSWORD = Read-Host 'Admin password' -MaskInput
    npm start

გამოიყენეთ მინიმუმ 16-სიმბოლოიანი უნიკალური პაროლი. გახსენით http://localhost:3000/ . ადმინისტრატორის მისამართია http://localhost:3000/analytics — ბრაუზერის შესვლის ფანჯარაში მომხმარებელია admin, პაროლი თქვენ მიერ მითითებული მნიშვნელობა. წარმოებაში ადმინისტრატორისთვის აუცილებელია HTTPS. ბაზა პირველივე გაშვებაზე ავტომატურად შეიქმნება.

## დეველოპერისთვის — კორპორაციულ ჰოსტინგზე განთავსება

1. გადაამოწმეთ, რომ ჰოსტინგი უშვებს მუდმივ Node.js 24 პროცესს, მხარს უჭერს ჩაშენებულ node:sqlite მოდულს და გამოყოფს მუდმივ, ჩაწერად დისკს. იმუშავებს Node-ის მხარდამჭერ მართვად ჰოსტინგზე ან VPS-ზე. მხოლოდ PHP-ს ან სტატიკური ფაილების ჰოსტინგისთვის სრული ფუნქციონალის გასაშვებად Node სერვისი ცალკე განათავსეთ და გამოიყენეთ მისკენ მიმართული ქვედომენი ან reverse proxy.
2. პროექტის საქაღალდე განათავსეთ საჯარო ფაილების დირექტორიის გარეთ. საჯარო მოთხოვნები მიაწოდეთ server.mjs-ს პროქსით. პირდაპირ ფაილურ წვდომას ნუ მისცემთ მონაცემთა ბაზაზე ან სერვერის კონფიგურაციაზე.
3. ჰოსტინგის გარემოს ცვლადებში მიუთითეთ ADMIN_PASSWORD, SITE_URL (ზუსტი გარე HTTPS მისამართი, მაგალითად https://aqualine.ge/black-friday/), PORT (ნაგულისხმევად 3000), DATA_DIR (მუდმივი დისკის აბსოლუტური ბილიკი). HOST ნაგულისხმევად 127.0.0.1-ია. კონტეინერის ქსელში საჭიროების შემთხვევაში გამოიყენეთ 0.0.0.0.
4. გაშვების ბრძანებაა node server.mjs. ჩართეთ სერვისის ავტომატური გაშვება გადატვირთვის შემდეგ. პროქსიმ უნდა შეინარჩუნოს სრული URL ბილიკი, query string, Origin და Authorization სათაურები. ქვესაქაღალდის შემთხვევაში გადაამისამართეთ მხოლოდ ამ კამპანიის პრეფიქსი. სარეკლამო ბმულები აიღეთ ამ გარემოს ადმინიდან.
5. გადაამოწმეთ მთავარი გვერდი, /01 და /20, ოთხი რუკის ბმული და ტელეფონის ღილაკი. /analytics-ზე შესვლის შემდეგ მიანიჭეთ ბმულს სახელი და გახსენით ახალ ბრაუზერში. განაახლეთ ანგარიში; დაამატეთ საცდელი შეთავაზება და შეამოწმეთ მისი ჩვენება, რედაქტირება და წაშლა. ქვესაქაღალდეში მისამართებს წინ ემატება არჩეული პრეფიქსი.

## მონაცემები და განახლება

ექსპორტი შეიცავს სრულ დამოუკიდებელ კოდსა და ვიზუალურ მასალას. სამუშაო SQLite ბაზა იქმნება ცარიელი, მასში ხელმისაწვდომია 20 წინასწარ განსაზღვრული ბმული. Sites-ში უკვე დაგროვილი ვიზიტები, შენახული სახელები და შეთავაზებები ამ არქივში არ შედის. განახლებისას შეინარჩუნეთ DATA_DIR. სარეზერვო ასლისთვის გააჩერეთ პროცესი და დააკოპირეთ მთელი მონაცემთა საქაღალდე; აღდგენისას დააბრუნეთ სარეზერვო ასლი იმავე ადგილას. გამოიყენეთ ერთი სერვისი მუდმივი ადგილობრივი დისკით.

index.html და style.css მართავს საჯარო გვერდს, admin.html — ბმულებსა და შეთავაზებებს, art/ შეიცავს სურათებს, ფონტებსა და ლოგოს. measure.js ითვლის შესვლებს, app.mjs ამუშავებს მოთხოვნებს, server.mjs უზრუნველყოფს HTTP-ს, ადმინისტრატორის შემოწმებასა და SQLite-ს. drizzle/*.sql არის ბაზის სქემა. შეცვლილი ფაილების ატვირთვის შემდეგ გადატვირთეთ სერვისი. დამოუკიდებელი ვერსიის გასაშვებად build არ არის საჭირო.
